# Auto Semmel Website

Create a premium, ultra-modern and fully responsive website prototype for a specialized German car dealership ("Autohaus") focusing on Italian brands (Alfa Romeo, Fiat, Abarth). The design language must blend "Italian passion & heritage" with high-end digital luxury (Dark Mode). Technical & UI Structure Requirements: 1. Design & Branding (La Passione): - Dark theme execution: Rich dark anthracite charcoal background (#121212) with elegant warm off-white typography. - Brand Accents: Use authentic Alfa-Red (#B90E0A) for primary actions and highlights. - Visual Separation: Create a subtle way to filter or switch the landing page vibe between "Alfa Romeo / Performance" (sporty, aggressive, carbon-textures) and "Fiat / Lifestyle" (chic, urban, clean). 2. Immersive Hero & Smart Search (Designed for Database Integration): - Hero section with a cinematic placeholder for a flagship sports car (e.g., Alfa Romeo Giulia Quadrifoglio) and the headline "La Passione per le Auto Italiane." - Integrated Multi-Filter Search Bar with the following inputs: * Condition (Neuwagen / Tageszulassung / Gebrauchtwagen) * Brand (All, Alfa Romeo, Fiat, Abarth) * Model (Dynamic placeholder) * Price Max (Slider or dropdown) * Gearbox (Automatik / Schaltgetriebe) - Include a prominent red "X Fahrzeuge anzeigen" button that simulates a dynamic count. 3. Advanced Vehicle Grid & Detail-Cards: - Display a grid of 4-6 realistic vehicle cards. Each card must include: * High-res image placeholder with a badge overlay ("MwSt. ausweisbar", "Top Deal", or "Elektro"). * Title (e.g., "Alfa Romeo Tonale 1.5 VGT MHEV TCT Veloce"). * Key Tech Specs icons: Year (EZ), Mileage (KM), Power (PS/kW), Fuel Type, Transmission. * Price prominently displayed (e.g., "38.900 €") and a secondary small text for monthly financing estimate (e.g., "ab 299 €/Monat"). * Action buttons: "Details ansehen" and a quick-action icon for "Probefahrt anfragen". 4. High-End Conversion & Lead Generation Sections: - "Werkstatt & Service" Hub: A dedicated modern section for service booking with a step-by-step interactive UI mockup (Select Service -> Choose Date -> Contact Info). - "Fahrzeugankauf" (We Buy Your Car): A clean multi-step form mockup where users can enter their current car details for a free valuation. 5. Future-Proof Code Architecture: - Use clean, modular React components. - Use Tailwind CSS for all styling. - Ensure all data structures for the cars are mapped in a clean local mock array (JSON format) so it can be easily replaced with Supabase database rows later. - Include a sticky glassmorphism navigation bar with placeholders for a logo, phone number, and opening hours.
